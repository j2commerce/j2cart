# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in J2Store / J2Commerce, please **do not** open a public GitHub issue.

Report it through our private security disclosure form:

**https://www.j2commerce.com/support/security-reports**

You can also reach us directly at **security@j2commerce.com**.

We will acknowledge your report and keep you informed as we investigate and address the issue.
